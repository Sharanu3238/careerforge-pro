\# CareerForge Pro - AI Resume Architect \& ATS Optimizer



CareerForge Pro is an AI-powered resume optimization system that analyzes resumes against job descriptions, calculates ATS scores, and generates improved resumes.



\## Features

\- Resume PDF upload

\- Job description keyword extraction

\- ATS score calculation

\- Resume improvement suggestions

\- PDF generation



\## Tech Stack

\- FastAPI

\- pdfplumber

\- FPDF
